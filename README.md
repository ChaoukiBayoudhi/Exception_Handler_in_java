# Exception Handler in Java

A project showing try, catch, finally and propagation use.

## Tech stack

- Java
- Lombok

## Concepts covered

Collections, console input (Scanner), custom exceptions, exception handling, lambda expressions.

## Project structure

- `Application`: Main
- `Exceptions`: ProviderNotFoundException, RequiredValueException
- `commandMgt`: Command, CustomersCommand
- `customerMgt`: Customer, Customers
- `productMgt`: Product, Products
- `providerMgt`: Provider, Providers

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).

The code uses Lombok annotations: add the Lombok library and enable annotation processing in your IDE.
